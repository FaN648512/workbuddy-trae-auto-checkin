如何获取 PushPlus 令牌（Token）

用于接收「签到失败」的微信通知 · 全程约 3 分钟 · 完全免费

一句话总览：到 PushPlus 官网用微信扫码登录 → 验证一次手机号 → 复制页面上那串 Token → 发给我。
有了它，只要签到失败、且你的电脑开着（WorkBuddy 登录着），你的微信就会立刻收到一条提醒。

这一步是在做什么

你现在的签到脚本每天会自动帮你领 WorkBuddy 和 Trae 的积分。绝大多数时候你是不需要管它的。

但万一某天它失败了（比如凭证过期、接口改了、网络问题），你希望马上知道，而不是积分悄悄漏掉好几天才发现。

问题在于：脚本只是一段后台程序，它自己没有能力给微信发消息。所以需要一个「中转站」——PushPlus 就是这样一个免费中转站：

签到脚本　→　PushPlus 服务器　→　你的微信

你只需要拿到一个「钥匙」（就是 Token），脚本才能通过这个中转站给你发消息。

操作步骤

1打开 PushPlus 官网

用手机或电脑浏览器访问：

https://www.pushplus.plus/

地址很好记：push（推送）plus（加）.plus，连起来就是 pushplus.plus。
2微信扫码登录

点击页面右上角的「登录」，会弹出一个二维码。用微信扫一扫扫描它，手机上点确认即可登录。

扫码的作用有两个：① 确认你是本人；② 把你的账号和这个微信绑定，以后消息才能发到这个微信上。
3完成手机号实名验证

登录后页面通常会提示你需要实名认证。这是国内推送类服务的合规要求，不是骗你信息，只验证手机号归属，不涉及身份证。

按提示操作，或直接访问验证页：

https://verify.pushplus.plus/

输入手机号 → 收到验证码 → 填入 → 完成。

跳过这一步的话，脚本调用接口时会返回 用户令牌不正确 —— 不是 Token 拿错了，而是实名没做完。
4复制你的 Token

在左侧菜单里找到「一对一推送」（有的界面在「发送消息」下面，叫「一对一发送」）。

页面上会显示一串 32 位左右的字符，那就是你的 Token。点旁边的复制按钮。

它长这样（下面是示例，不是真的）：

a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6

找不到的话，也可以看「个人中心」或「用户中心」页面，Token 一般会显示在那里。
5把 Token 发给我

直接把这串字符粘贴到对话里发给我就行。我会：

  1. 写进你本机的配置文件（config.json 的 notify.token 字段）
  2. 立刻发一条测试通知，让你亲眼看到微信收到消息
  3. 再模拟一次「签到失败」，验证整条链路真的通

常见问题

Q：实名认证会不会泄露个人信息？

A：PushPlus 只验证手机号，不需要身份证。这是工信部对推送类服务的常规要求，所有类似平台（Server酱等）都一样。

Q：免费额度够用吗？

A：免费版每天 200 条。你只有在签到失败时才会收到推送，正常情况一个月可能 0 条，完全用不完。

Q：Token 会不会过期？

A：不会自动过期。只要你不主动重置或注销账号，它会一直有效。

Q：以后想换一个接收微信怎么办？

A：重新扫码登录一个新的 PushPlus 账号，把新 Token 发我替换即可，1 分钟搞定。

Q：能不能不发微信，改成别的？

A：可以。脚本同时支持企业微信群机器人、飞书机器人、Server酱、iOS Bark。改配置里的一行就能切换，需要时告诉我。

安全性说明

项目 说明
Token 存在哪 只写进你本机的 auto_checkin/config.json，不写入日志、不上传任何地方
Token 能做什么 只能给你推送消息。它不能读取你的微信、不能登录你的账号、不能做任何其他操作
别人拿到会怎样 最多给你发几条垃圾推送。发现异常可在 PushPlus 后台「重置 Token」立即作废
脚本会打印它吗 不会。通知发送只输出「成功 / 失败」，从不输出 Token 内容
